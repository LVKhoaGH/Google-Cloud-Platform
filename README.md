# Google Cloud Platform (GCP) Infrastructure Lab

## 📌 Project Overview
Báo cáo và cấu hình chi tiết về việc triển khai hạ tầng mạng doanh nghiệp trên nền tảng GCP. Dự án tập trung vào khả năng mở rộng (Scalability), tính bảo mật (Security) và giám sát hệ thống (Observability).

## 🛠 Tech Stack
* **Cloud Platform:** Google Cloud Platform (VPC, Compute Engine, Cloud Monitoring).
* **Networking:** VPC Peering, Firewall Rules, Implicit Routes.
* **Security:** Tag-based Security Policies, Least Privilege Principle.
* **Automation:** Git for version control.

## 📂 Project Structure
* `GoogleCloudPlatform.docx`: Báo cáo kỹ thuật chi tiết (Final Report) chuẩn Enterprise/ISP.
* `README.md`: Hướng dẫn và tóm tắt dự án.

## 🚀 Key Implementations
1. **Network Isolation:** Thiết lập Custom Subnets để quản lý dải IP riêng biệt.
2. **Inter-VPC Connectivity:** Cấu hình VPC Peering 2 chiều đảm bảo tính hội tụ (Convergence).
3. **Cloud Observability:** Triển khai Monitoring Dashboard và Alerting Policies để đảm bảo SLA.
4. **Log Analysis:** Sử dụng VPC Flow Logs cho mục đích audit và bảo mật.
